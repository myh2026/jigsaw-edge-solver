# 2048 决策图自训练（图在做决策）

按"图自训练、训练的是决策本身"实现：**图 = 决策树**，内部节点是决策测试、
叶节点是决策（方向）。运行时从根走到叶，叶子就是这一步的决策。

## 训练循环（GraphDojo 语义）

| 环节 | 实现 |
|:---|:---|
| 冷启动 | 图为空，教师（expectimax 深 2/3）兜底播种状态-决策对 |
| 挂载 | 归纳出初始决策图（决策树），挂载执行 |
| 自对弈 | 图做决策（仅决策非法时教师兜底），记录每一步 |
| 误差归因 | 一步前瞻估值找"后悔决策"；这些状态必须由教师给出正确决策 |
| 结构精炼 | 只用后悔样本 + 25% 随机样本重归纳决策树（新分支 = 图长出新决策） |
| 验证/回滚 | 留出决策集上的决策一致性（或对局验证）提升才接受，否则回滚到最佳图 |

## 结果（`graph_decision_selftrain_results.md`）

- 决策图从 **46 叶长到 108 叶**；图决策覆盖率 **77% → 84%**；
- 留出决策集上与教师决策的一致性 **28.4% → 33.6%**（4 类动作，随机基线 25%）；
- 对局验证最好到 427，但**独立终评新局只有 64–256**（方差大、泛化不足）。

## 诊断（为什么决策图不强）

1. **决策粒度不够**：4 类动作的树在 28 个可解释特征上，与深搜决策一致性
   只能到 ~33%——2048 的最优决策依赖细粒度盘面模式与价值估计，决策树
   学到的是粗原则；
2. **验收信号与目标错位**：用对局最大方块做验收噪声极大（单局方差 ±2 档），
   用决策一致性做验收则与"赢"不直接相关；
3. **分布漂移**：树在自对弈状态上训练、在教师状态上评估，DAgger 修正
   进展缓慢。

## 与其他两条自训练路线对比

| 路线 | 图是什么 | 训练信号 | 真实游戏成绩 |
|:---|:---|:---|:---|
| **决策图（本文）** | 决策树（测试+动作叶） | 自对弈后悔 + 教师纠错 + 回滚 | 64–256 |
| 评分图（ES 自对弈） | 特征→权重边→动作 | 自对弈胜负 + 只留更强版本 | **2048 / 25600 分** |
| 深度蒸馏 + 混合路由 | 浅搜索图 | 教师深搜蒸馏 | **1024（超教师）** |

结论：在这个游戏上，"可解释决策图"忠实于"图做决策"，但表达力不足；
"评分图"表达了决策偏好，训练自对弈后足以打出 2048。要两者兼得，
下一步应把**决策节点与局部搜索结合**（决策图决定策略/优先级，叶节点内做浅搜索），
而不是继续加深可解释树。
