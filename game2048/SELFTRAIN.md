# 2048 图自训练（GraphDojo 范式）

目标：不手写策略，让图从自己的对局中训练、变强。

## 图的表示与训练循环

- **图**：6 个特征节点（空格数 / 单调性 / 平滑度 / 合并潜力 / 最大块在角 / 蛇形对齐）
  → 权重边 → 4 个动作节点（方向）。图的参数就是这 6 个权重。
- **训练**：自对弈 + 演化选择（无教师）。
  1. 每代围绕当前权重采样一组候选图（高斯扰动，σ 逐代衰减）；
  2. 每个候选图在固定种子的自战局上评估；
  3. **只保留比历史最佳更强的图**（挂载/回滚纪律，等价 GraphDojo 的隔离区验证）；
  4. 迭代：图只靠自己的对局变强。

## 负结果（诚实记录）

1. **查表式自训练**（`graph_selftrain.py`）：情境键（空格/合并掩码/角落/最大幂）
   -> 动作查表，教师纠错 + 局级回滚。结果覆盖率虚高、成绩不稳（终局 64-256）——
   粗粒度键在多棋盘间发生规则冲突。教训：图的表示比训练流程更关键。
2. **统计克隆**（`distill_2048.py` 中的纯蒸馏部分）：直接克隆深搜教师，
   留出一致性 31-45%，上路分布漂移崩溃（最大 64-256）。深搜策略的行为克隆
   需要 DAgger 类交互修正。

## 追加：LLM 教师（DeepSeek）

`llm_teacher.py`：从教师对局采样 240 个盘面，批量询问 DeepSeek（30 次调用，
tokens 14314/737），以 LLM 决策为标签训练决策图，再请图上场。

| 指标 | 值 |
|:---|:---|
| LLM 有效决策 | 240/240 |
| **LLM 与深搜最优决策一致率** | **30.0%**（4 类动作，随机基线 25%） |
| 图（LLM 教）留出与 LLM 一致率 | 68.8% |
| 图（LLM 教）实战 | 128 / 64 / 256 |

结论：LLM 在 2048 上单步决策只有 30% 与深搜最优一致——它能"教"，但教得
比搜索弱；图能较好地压缩 LLM 的决策（68.8%），于是继承了 LLM 的上限。
GraphDojo 的完整形态应是 **LLM 教 + 搜索/对局验证纠错**：LLM 负责语义与
冷启动，验证门与自对弈负责把弱教师压成不弱于它的墙。
