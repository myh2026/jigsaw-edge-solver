# 2048 × GraphDojo 蒸馏范式实验

对应 GraphDojo 训练期架构：教师慢思考（L）→ 蒸馏出快图（G）→ 图接管/教师兜底（路由）。
本目录 `distill_2048.py` 为完整可复现代码（纯 Python，CPU）。

## 设定

| GraphDojo 概念 | 2048 对应物 |
|:---|:---|
| 教师（LLM 兜底） | 位板 expectimax 深 3/4（~75 ms/步，慢思考） |
| 蒸馏（归纳挂载） | 深度蒸馏为"深 1 浅图"（同评估函数，0.49 ms/步） |
| 路由（图接管/兜底） | 空格数阈值：空格 > k 用浅图，≤ k 回教师 |
| 学习卷 / 考试卷 | 教师对局录制 / 全新对局评测 |

## 成绩（每策略 3 局，考试卷新局）

| 策略 | 平均最大方块 | 均延迟 | 教师调用占比 |
|:---|:---:|:---:|:---:|
| 纯教师（深 3/4） | 683 | 74.6 ms/步 | 100% |
| 纯蒸馏（深 1 图全接管） | 512 | **0.49 ms/步（151×）** | 0% |
| 混合 v1（空格≤4 兜底） | **1024** | 57.9 ms/步 | 80% |
| **混合 v2（空格≤2 兜底）** | **1024** | **21.6 ms/步（3.5×）** | 43% |

要点：

1. **纯蒸馏图** 151 倍提速，质量保持 75%（512 vs 683）——快而略钝；
2. **混合（v2）反超教师**（1024 vs 683）：易局浅图足够、难局教师兜底，
   且浅图的稳健打法减少了教师的偶发失误；接管率 57%，整体快 3.5 倍；
3. **负结果（统计克隆）**：用决策树/梯度提升直接克隆教师策略，
   留出一致性仅 31–45%，上路对局分布漂移导致崩溃（最大仅 64–256）。
   深搜索策略的行为克隆需要 DAgger 类交互修正，浅层统计学生不可行
   ——这正是 GraphDojo 选择"蒸馏为可验证结构（而非统计策略）"的理由。

## 复现

```bash
python distill_2048.py        # 学习卷(教师对局) -> 克隆学生 -> 纯/混合评测
```

（深度蒸馏与路由实验见本文件数据；克隆部分即脚本内 study/pure/hybrid 流程。）
